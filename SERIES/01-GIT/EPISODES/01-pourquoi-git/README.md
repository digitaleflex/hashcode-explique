# Épisode 01 — Pourquoi Git existe ?

## Série
Série 01 — GIT

## Format
6 visuels — 1080 × 1080 px

## Objectif pédagogique
Faire comprendre le problème humain et technique auquel Git répond avant d'introduire les commandes.

## Message central
> Git permet de suivre, comprendre et maîtriser l'évolution d'un projet dans le temps.

## Structure des 6 visuels

### Visuel 01 — Couverture
**POURQUOI GIT EXISTE ?**

Avant Git, travailler sur du code pouvait vite devenir un chaos.

Signature : **HASHCODE EXPLIQUE · SÉRIE 01 — GIT**

### Visuel 02 — Le problème
**Tu modifies ton projet.**

Exemple :
- projet-final
- projet-final-v2
- projet-final-v2-final
- projet-final-v2-final-ok
- projet-final-v2-final-ok-def
- projet-final-vraiment-final

Question : **Ça te semble familier ?**

### Visuel 03 — Quand le projet grandit
**Et quand plusieurs personnes travaillent dessus ?**

Questions :
- Qui a changé quoi ?
- Quand ?
- Pourquoi ?
- Comment revenir en arrière ?

### Visuel 04 — Le problème central
**COMMENT GARDER LE CONTRÔLE DE L'HISTORIQUE DU PROJET ?**

Concepts introduits :
- Versionner
- Comparer
- Revenir en arrière
- Collaborer

### Visuel 05 — La réponse
**C'est précisément le problème que Git vient résoudre.**

Flux :
MODIFIER → VERSIONNER → COMPARER → REVENIR EN ARRIÈRE → CONSERVER L'HISTORIQUE

Message :
> Git permet de suivre l'évolution d'un projet dans le temps.

### Visuel 06 — À retenir
**GIT ≠ JUSTE DES COMMANDES**

Git est un **système de contrôle de version**.

À retenir :
**HISTORIQUE · VERSION · ÉVOLUTION · CONTRÔLE**

Teaser :
> Dans le prochain épisode : Qu'est-ce que Git, exactement ?

Signature :
**HASHCODE EXPLIQUE — Comprendre. Pratiquer. Construire.**
