# HashCode Explique

**Comprendre. Pratiquer. Construire.**

HashCode Explique est la bibliothèque éditoriale et pédagogique de HashCode dédiée à la vulgarisation des technologies et des pratiques numériques.

L'objectif est simple : rendre les concepts techniques accessibles sans les simplifier à l'excès.

## Format pédagogique

Chaque épisode suit par défaut 6 slides :

1. **Hook** — attirer l'attention
2. **Problème** — partir d'une situation réelle
3. **Concept** — expliquer simplement
4. **Fonctionnement** — visualiser
5. **Application** — montrer l'utilité réelle
6. **À retenir / Action** — synthétiser et faire pratiquer

## Principe éditorial

> Pas de jargon sans explication.  
> Pas de théorie sans exemple.  
> Pas de concept sans application.  
> Pas d'explication sans possibilité de pratiquer.
